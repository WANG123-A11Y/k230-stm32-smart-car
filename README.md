# K230 + STM32F407 视觉/语音智能小车

> 本科课程设计（小组）。K230 板端 YOLO11 视觉检测 + 语音指令识别，经 UART 驱动 STM32F407
> 完成目标跟随、云台随动与闭环调速；视觉与语音分线程并行，语音识别期间不丢帧。

## 关于本仓库

本项目是**小组课程设计**，系统由多名同学分工完成，代码与文档由本人整理归档以便完整复现。

- **本人负责：K230 端语音助手模块**（方案选型、按键对讲/VAD 采集、云端识别接入、
  HTTP 健壮性修复、抗误触发策略、三端提示音链路联调）与 K230 侧集成代码维护、本文档撰写。
- 视觉检测与模型部署、STM32F407 运动控制、云台执行板等部分由组内其他成员完成，一并归档在此。

## 系统架构

```
┌─────────────── K230（01Studio CanMV，MicroPython）───────────────┐
│  视觉线程：YOLO11 kmodel 板端推理 → 目标框 → C: 帧               │
│  语音线程：麦克风采集 → VAD/按键对讲 → 云端短语音识别 → 词表匹配  │
│                              ↓ UART2 115200 8N1                  │
└──────────────────────────────────────────────────────────────────┘
                               ↓
┌────────────────── STM32F407（主控 / HAL）────────────────────────┐
│  4 路编码器测速 + 增量式 PID 闭环调速（TIM8 PWM）                 │
│  C:/V:/B: 帧解析；USART3 → C06B 云台帧；B: → F103 0x04 蜂鸣器帧   │
└──────────────────────────────────────────────────────────────────┘
                               ↓ USART3 / 0x04 帧
┌──────────── STM32F103（云台执行：舵机 PWM / OLED / 蜂鸣器）──────┐
└──────────────────────────────────────────────────────────────────┘
```

## 硬件

| 部件 | 说明 |
|---|---|
| 主控（视觉+语音） | 01Studio CanMV K230（板载麦克风、板载 2.4G WiFi、3.5" MIPI 屏） |

## 通信协议

### K230 → STM32F407（UART2，115200 8N1，ASCII 行协议）

| 帧 | 含义 | 示例 |
|---|---|---|
| `C:<类别>,X:<cx>,Y:<cy>,W:<w>,H:<h>,S:<置信%>,A:<面积千分比>` | 检测结果（图像 800×480，中心 (400,240)） | `C:4,X:412,Y:238,W:96,H:80,S:87,A:142` |
| `C:-1,...` | 目标丢失 → STM32 停车 + 云台三档扫描 + 车体自转检索 | |
| `V:START` / `V:STOP` / `V:ACC` / `V:DEC` | 语音指令，等效物理按键 K0（启停）/ K1（档位 ±1，20/40/60/80 RPM） | |
| `B:1` / `B:0` | 蜂鸣器响 / 提前停（F407 收到后组 `0x04` 帧转发 F103） | |

### STM32F407 → C06B 云台（USART3）

```
0xAA 0x01 <水平角> <俯仰角> <校验和> 0xBB
```

## 语音助手模块（本人负责部分）

**方案选型**：对比"板端离线识别（需换 Linux 系统、视觉代码全部重写）"与"外接离线语音模块
（词表烧死、演示不灵活）"后，选定 **板载麦克风 + 板载 2.4G WiFi + 云端短语音识别**——
中文识别准、词表改几行代码即可、零额外硬件；代价是依赖网络与约 1 秒延迟。

**实现要点**

- **双触发模式**：`auto` 全自动 VAD 监听（底噪自适应，能量双阈值 + 起止/静音绝对门限）；
  `key` 按键对讲（KEY=GPIO21，按下开始、再按结束，0.3 s 蜂鸣提示，单次上限 2 s）——答辩演示用
- **采样率适配**：实测该固件**忽略请求的 16 kHz、实际按 44.1 kHz 采集**（录音回放呈快进音、
  识别必失败）→ 改为按 44.1 kHz 采集后线性降采样至 16 kHz 上传
- **HTTP 健壮性**：识别接口响应为 **chunked 分块传输**且该固件 `socket.recv` 会提前返回 →
  按 `Content-Length` 循环收满 + 解 chunked 帧，JSON 才能完整解析
- **抗误触发**：句内有效语音占比门槛、信噪比双阈值、**同一指令 8 秒内说两次才下发**、
  指令优先级（停 > 启 > 减 > 加）、下发后冷却 1.2 s
- **线程模型**：语音与视觉分线程（`_thread`），共用 UART 加写锁，识别期间视觉不丢帧
- **三端提示音链路**：K230 发 `B:` → F407 转 `0x04` 帧 → F103 驱动蜂鸣器

**实测**：语音"开始。" → 识别返回"开始" → 正确下发 `V:START`；随口语句（"对呀！""我去，终于能识别。"）
均能准确转写，链路稳定。

## 部署

1. 将 `yolo11s_det_640.kmodel` 放入 K230 的 `/sdcard/`
2. 编辑 `k230/main.py` 顶部配置，填入 `WIFI_SSID` / `WIFI_PWD` / `BAIDU_TOKEN`，
   拷贝到 `/sdcard/main.py` 即上电自运行；也可用 CanMV IDE 直接运行调试
3. STM32F407 侧应用 `stm32/main.c`（改动全部位于 `USER CODE` 区，替换原工程对应文件后重新编译）
4. 云端识别需在百度智能云开通"短语音识别"，用 API Key / Secret Key 换取 `access_token`
   （30 天有效，过期需重换）

> 未配置网络或 token 时，程序自动只跑视觉，原功能不受影响。
